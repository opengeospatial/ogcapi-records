== Relationship to STAC (Informative)

https://docs.ogc.org/DRAFTS/26-026.html[OGC API - Records - Part 5: STAC] defines how records and catalogs use the extensions of the https://stacspec.org[SpatioTemporal Asset Catalog (STAC)] specification, and how records and catalogs can be valid STAC Items and STAC Collections at the same time. It also compares this Standard with STAC and https://github.com/radiantearth/stac-api-spec/tree/v1.0.0[STAC API] and gives guidance for implementing both.
