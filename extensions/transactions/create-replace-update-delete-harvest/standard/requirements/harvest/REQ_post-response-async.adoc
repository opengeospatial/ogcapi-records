[[req_harvest_post-response-async]]
[width="90%",cols="2,6a"]
|===
^|*Requirement {counter:req-id}* |*/req/harvest/post-response-async* 
^|Condition: |The operation is invoked asynchronously
^|A |A successful execution of the operation SHALL be reported as a response with a HTTP status code `201`.
^|B |The header of the response SHALL return the `Location` header that contains a link to the newly created job.
^|C |The body of the response SHALL conform to the following JSON-Schema fragment:

[source,yaml]
----
include::https://schemas.opengis.net/ogcapi/processes/part1/1.0/openapi/schemas/statusInfo.yaml[]
----

^|D |That value of the `type` member in the https://schemas.opengis.net/ogcapi/processes/part1/1.0/openapi/schemas/statusInfo.yaml[statusInfo.yaml] response SHALL be `ogc-catalog`.
|===
