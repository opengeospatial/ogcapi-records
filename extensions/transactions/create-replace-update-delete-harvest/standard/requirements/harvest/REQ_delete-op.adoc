|===
^|*Requirement {counter:req-id}* |*/req/harvest/delete-op*
^|A |For every catalog (path: `/collections/{collectionId}`) where the `itemType` is `record`, the server SHALL support the HTTP DELETE operation at the path `/collections/{catalogId}/harvest/{harvestReqId}`.
