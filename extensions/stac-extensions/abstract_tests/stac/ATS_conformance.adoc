[[ats_stac_conformance]]

[abstract_test]
====
[%metadata]
identifier:: /conf/stac/conformance
target:: /req/stac/conformance
test-purpose:: Validate conformance identification.
test-method::
+
--
. If the deployment provides records through an API and all of its records and catalogs pass the tests of this conformance class, issue an HTTP GET request on the `/conformance` path and verify that the `conformsTo` array contains the value `+http://www.opengis.net/spec/ogcapi-records-5/1.0/conf/stac+`.
. If the deployment is a crawlable catalog, verify for each catalog that passes the tests of this conformance class, together with all of its records, that the `conformsTo` member of the catalog contains the value `+http://www.opengis.net/spec/ogcapi-records-5/1.0/conf/stac+`.
--
