[[rec_stac_links]]

[recommendation]
====
[%metadata]
identifier:: /rec/stac/links
part:: The `href` of the `self` link of a record or catalog SHOULD be the absolute URI under which the record or catalog is served.
part:: If a record or catalog has a preferred location that differs from the URI under which it is served, this location SHOULD be provided in a link with the relation type `canonical` and not in the `self` link.
part:: All links in the responses of an API SHOULD use absolute URIs.
part:: An API that serves a resource both with and without a trailing slash in its path SHOULD redirect the variant with the trailing slash to the variant without it.
====

NOTE: OGC API Standards do not specify the base URI for resolving relative URIs, so RFC 3986 applies and the base URI is the URI from which the document was retrieved. The STAC best practices use the `self` link as the base URI instead. The two only lead to the same result if the `self` link is the URI under which the document is served. A `self` link in each record is already recommended by https://docs.ogc.org/is/20-004r1/20-004r1.html#rec_record-core_links[`/rec/record-core/links`] of <<OGC20-004r1,OGC API - Records - Part 1: Core>>. See <<clause_links,Links and URL resolution>>.
