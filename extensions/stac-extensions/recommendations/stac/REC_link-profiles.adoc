[[rec_stac_link-profiles]]

[recommendation]
====
[%metadata]
identifier:: /rec/stac/link-profiles
part:: A link with the media type `application/json` that points to a catalog SHOULD include the `profile` member with the value `["http://www.opengis.net/def/profile/OGC/0/ogc-catalog"]`.
part:: A link that points to a record SHOULD include the `profile` member with the value `["http://www.opengis.net/def/profile/OGC/0/ogc-record"]`.
part:: If a link includes the `profile` member, the target SHOULD include a link with the relation type `profile` to each of these profiles.
====

NOTE: The `profile` member of a link is defined by https://docs.ogc.org/is/20-004r1/20-004r1.html[OGC API - Records - Part 1: Core] and is allowed as an additional member of links in STAC. It tells clients of OGC API - Records what the target of a link is before they retrieve it, even if the link uses a generic media type such as `application/json`. After retrieval, a link with the relation type `profile` in the target tells the same (see https://www.rfc-editor.org/rfc/rfc6906[RFC 6906]), also if the document is no longer available from its original location, for example after it was downloaded. As the value is an array, further profiles can be added.
