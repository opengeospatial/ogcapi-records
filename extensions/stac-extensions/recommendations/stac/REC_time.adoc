[[rec_stac_time]]

[recommendation]
====
[%metadata]
identifier:: /rec/stac/time
part:: A record SHOULD include a `time` member that describes an instant or interval that is equivalent to the one of the `datetime`, `start_datetime`, and `end_datetime` members in its `properties`.
====

NOTE: This recommendation is most relevant when records are generated from existing STAC Items. Both use UTC, but timestamps in the `time` member always end with `Z`, while STAC also allows the offset `+00:00`. Such timestamps need to be rewritten with `Z`.
