[[req_stac-extensions_crawlable-catalog]]

[requirement]
====
[%metadata]
identifier:: /req/stac-extensions/crawlable-catalog
part:: In a crawlable catalog, each catalog object that uses STAC extensions, or whose records use them, SHALL include the URI `http://www.opengis.net/spec/ogcapi-records-5/1.0/conf/stac-extensions` in its `conformsTo` member.
====

NOTE: A crawlable catalog has no `/conformance` endpoint. This requirement therefore follows the pattern of the `/req/crawlable-catalog/conformance` requirement in https://docs.ogc.org/is/20-004r1/20-004r1.html[OGC API - Records - Part 1: Core], which places the conformance declaration in the catalog object.
